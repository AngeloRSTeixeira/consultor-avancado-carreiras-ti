# Consultor Avançado de Carreiras em TI

Sistema Especialista baseado em regras com tratamento de incerteza e pontuação ponderada, em Python + Streamlit. Calcula a compatibilidade com 10 trilhas de TI, identifica lacunas de competências e gera um roadmap individual.

> Trabalho da disciplina de Inteligência Artificial — Ciência da Computação, UNIPAC Barbacena.
